## 3. 用对了才有感觉 · 多轮是灵魂 ⭐

### ✅ 推荐工作流

```
开始圆桌
   ↓
圆桌生成（3 顾问 · 2 阶段 · 1 Moderator · 约 30-60s）
   ↓
读完 Moderator 的「她在听到什么 / 你可以尝试 / 仍然存疑」
   ↓
想追问 → 滚到底部，找到 ⭐【继续追问】⭐ 按钮
   ↓
在同一个 session 里输入新问题（带着上一轮的心情）
   ↓
第 2 轮会**自动承接**第 1 轮的视角 · Moderator 开头会明说"上一轮你说了 X"
```

### ❌ 不要这样做

| 错误做法 | 后果 |
|:---|:---|
| 读完回到左侧栏，重新点「圆桌讨论」开新 session | **丢掉所有跨轮记忆** · 第 2 轮又从零开始 |
| 关浏览器标签页再打开 | 会话仍在 · 下次从历史列表点进去可**只读回顾**，但要继续必须用底部的「继续追问」 |

> **关键一句话**：**所有追问都在同一个 session 的「继续追问」按钮里发生** · 这是 v1.0 的灵魂所在。

## 5. 有一个底线 · 请务必知道

**圆桌讨论是非诊断性的探索工具 · 不能替代专业心理咨询或医疗评估。**

如果你正在经历严重情绪困扰，**请优先拨打 24 小时心理援助热线 `400-161-9995`。**

所有顾问的回应都经过 `CrisisDetector + BiasDetector` 双层过滤，但**人类的情感需要人类的陪伴**，这是 Lens 的底线。

## 6. 怎么给我们反馈

### 路径 A · 产品内（推荐）

右下角常驻 **「💬 反馈」浮动按钮** · 点开写几句即可 · 自动带上当前页面和浏览器信息。
反馈落盘到 `advisor_out/feedback/ui_feedback.jsonl` · 我们每天早上复盘。

### 路径 B · 结构化问卷

我们想了解的是这 **5 个维度**（每次 session 后花 2 分钟即可）：

1. **真实度**（1-5）· 顾问的回应让你觉得"真的有人在听"吗？
2. **新视角**（1-5）· 有没有一句话让你有"啊原来还能这样看"的感觉？
3. **承接感**（1-5 · 多轮才评）· 第 2 轮有没有续上第 1 轮的温度？
4. **节奏**（1-5）· 等待时长 / 流式打字速度 / 界面停顿是否让人焦躁？
5. **被冒犯点**（自由文本）· 有没有让你皱眉的一句话 / 一个用词 / 一个 UI 元素？

把这 5 个回复塞进 💬 反馈按钮，或邮件直发项目组。

## 7. 常见问题 FAQ

### Q1 · 第 2 轮 Moderator 说「已降级」，是不是记忆丢了？

**不会丢。** v1.0.0（2026-04-30）已修复：规则模板降级路径也会注入上一轮的 `seen/tries/doubts/lens`。
如果你在 banner 里看到「已承接上一轮要点」字样，就说明跨轮记忆 OK。

### Q2 · 为什么等了 30 秒还没开始？

3 位顾问 phase1 是**并发**启动的 · 但每位顾问本身要等 LLM 首 token（3-10s）。
如果超过 60 秒仍无反应 · 大概率是 LLM backend 被限流 · 刷新页面重试即可。

### Q3 · 我可以改 persona 组合吗？

**单次 session 内不可** · 但你可以回到 `/roundtable` 开一个新 session，用不同组合。
建议先用默认 3 位把问题聊完，想换视角再开新的，这样能横向对比。

### Q4 · 我的数据会被发到哪里？

- 问题 + 回答 · 落盘到你本机的 `advisor_out/roundtable/sessions/` · 只在本机
- LLM 调用 · 会发送到你在 `.env.advisor` 配置的 API provider（默认 Claude）· **不经过 Lens 服务器**
- 反馈 · 落盘到本机 `advisor_out/feedback/` · 你同意后我们才会 pull

详见「设置 → 隐私策略」页。

### Q5 · RAG 注入（勾选片段）什么时候用？

**继续追问**时才会出现 · 可以从之前的聊天记录 / 知识手册里勾 1-3 个片段当背景。
不知道勾什么就**别勾** · 不影响体验。
